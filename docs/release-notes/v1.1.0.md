# 羽记 FeatherNote v1.1.0 发布说明

> **轻盈如羽，行云流水 —— 跨平台离线 Markdown 笔记与待办应用**

---

## 🌟 核心更新

### 🖥️ 1. 桌面与平板全面适配
- 首页、搜索、归档箱与废纸篓新增 1200px 内容区，按窗口宽度自动切换 2 / 3 / 4 列卡片。
- 设置页、编辑器正文与底部工具栏限制为 760px 舒适阅读宽度，不再横跨整个屏幕。
- 宽屏编辑模式支持左右分屏：左侧编写 Markdown，右侧实时预览。
- 窄屏与 1.2× 字号下，编辑页顶部栏自动调整，返回、编辑/预览切换与操作按钮不再重叠。

### 📖 2. 更清爽的阅读体验
- 笔记卡片摘要会清洗 Markdown 标记、列表符号与任务复选框，不再出现 `**粗体**`、`- [x]` 等原始语法。
- 标签与日期字号提升，标签对比度增强，浅色与深色主题下都更易读。
- 标签统一显示为 `#标签`，编辑页、卡片与分享书笺保持一致。
- 长标题分享卡不再出现孤立的羽毛 emoji 换行，书笺排版更稳定。
- 空状态动画缩短为 1.5 秒，并遵循系统「减少动态效果」设置。

### ♿ 3. 无障碍与本地化
- 接入 Flutter 官方本地化，界面语义统一为简体中文，系统读屏不再播报英文按钮。
- 系统字号缩放与应用内字号设置改为叠加生效，不再互相覆盖。
- 为编辑器标题/正文、搜索框、编辑与预览切换、颜色选择、待办勾选等补充语义标签和选中状态。
- 扩大更多操作、清空搜索、删除标签、颜色色块等控件的点击区域。

### ⚙️ 4. 交互与反馈
- 搜索首次加载新增骨架屏，并显示「找到 N 条笔记」结果数量。
- 归档箱卡片点击可直接打开笔记；长按或更多按钮仍可取消归档、移入废纸篓。
- 删除待办与清空已完成待办增加二次确认，避免误操作。
- 删除笔记失败时不再直接退出编辑器，错误会通过提示反馈。
- 抽屉版本号改为读取应用真实版本，并修正「全部笔记 / 待办清单」的选中状态。

### 💾 5. 备份与恢复
- 导出改为生成真实 JSON 文件，包含笔记、归档/废纸篓内容以及标签名称与颜色配置。
- 导入支持选择 `.json` 文件或直接粘贴文本，导入前展示笔记与标签数量并提示同 ID 覆盖。
- 兼容旧版仅含笔记数组的备份文件；导入时按名称合并标签，并同步颜色配置。

---

## 🐛 问题修复
- 修复 Markdown 摘要中 `- [x]` 被错误显示为 `- x`、列表符号残留的问题。
- 修复备份导出不含标签颜色、归档与废纸篓笔记的问题。
- 修复抽屉固定显示 v1.0.0、与设置页版本不一致的问题。
- 修复删除笔记失败仍退出编辑页的问题。
- 修复 320px 窄屏配合大字号时编辑页顶部栏按钮重叠的问题。
- 修复首页、搜索、归档与废纸篓在桌面端固定两列、内容过宽的问题。
- 升级文件选择与分享依赖，修复 Android 新版 Gradle 构建兼容性问题。

## 📦 安装与下载（仅 Android）

发布流水线只构建以下三个 Android 安装包：

| 安装包 | 适用设备 | 说明 |
| :--- | :--- | :--- |
| 🤖 `FeatherNote-Android-arm64-v8a-v1.1.0.apk` | 绝大多数现代 64 位 Android 手机 | **推荐**，体积最小 |
| 🤖 `FeatherNote-Android-armeabi-v7a-v1.1.0.apk` | 老旧 32 位 ARM 设备 | 兼容性优先 |
| 🤖 `FeatherNote-Android-Universal-v1.1.0.apk` | 全部架构（含 x86_64 模拟器） | 通用包，体积稍大 |

> iOS / macOS / Windows / Linux / Web 版本不再随 Releases 发布；如需使用请在本地自行编译（见仓库 README 的「打包构建」章节）。
